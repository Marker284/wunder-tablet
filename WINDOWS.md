# Запуск TUI на Windows

Инструкция для рабочего ПК, с которого настраиваются школьные планшеты.
Всё, что ниже, делается один раз; дальше — только `python launcher_tui.py`.

---

## 1. Что скопировать на компьютер

Положите в одну папку, например `C:\WunderTablet\`:

```
C:\WunderTablet\
├── launcher_cleanup.py     ← движок, обязателен
├── launcher_tui.py         ← сам TUI
├── hmdm.apk                ← APK MDM-агента, ставится автоматически
└── platform-tools\         ← распакованный adb от Google
    ├── adb.exe
    ├── AdbWinApi.dll
    └── AdbWinUsbApi.dll
```

`inventory.csv` и папка `logs\` появятся сами при первом прогоне.

## 2. Python

Скачайте с [python.org](https://www.python.org/downloads/windows/) версию 3.10
или новее. При установке **обязательно** поставьте галочку
**«Add python.exe to PATH»** на первом экране — иначе команда `python` не
заработает.

Проверка в PowerShell:

```powershell
python --version
```

Должно ответить `Python 3.1x.x`.

## 3. Модуль curses

В Linux и macOS он входит в стандартную библиотеку, **в Windows его нет** —
ставится отдельным пакетом:

```powershell
pip install windows-curses
```

Без него скрипт честно скажет, чего ему не хватает, и завершится.

## 4. ADB

Если папки `platform-tools` ещё нет — скачайте
[SDK Platform Tools для Windows](https://developer.android.com/tools/releases/platform-tools)
и **распакуйте её целиком рядом со скриптами**, как в схеме выше. Больше ничего
делать не нужно: скрипт сам найдёт `adb.exe` в такой папке.

Порядок поиска: ключ `--adb` → переменная `ADB` → `PATH` → папка со скриптом →
вложенные папки, `platform-tools` в первую очередь → типовые места установки
Android SDK.

Задавать путь вручную нужно, только если папка лежит где-то ещё:

```powershell
$env:ADB = "D:\tools\platform-tools\adb.exe"
```

Проверка — запустите скрипт, в первой же строке он пишет, какой adb взял:

```
• adb: C:\WunderTablet\platform-tools\adb.exe (Android Debug Bridge version 1.0.41)
```

В TUI путь виден в мастере настройки строкой `adb: ...` — зелёным, если найден,
красным, если нет.

## 5. Драйверы USB и отладка на планшете

1. На планшете: **Настройки → О планшете** → 7 раз нажать **Номер сборки** →
   появится «Для разработчиков».
2. **Настройки → Для разработчиков** → включить **Отладка по USB**.
3. Подключить планшет кабелем, на экране планшета нажать **Разрешить** в
   запросе «Разрешить отладку по USB?» и поставить галочку «Всегда разрешать».

Если Windows не видит планшет, поставьте драйвер:
[Google USB Driver](https://developer.android.com/studio/run/win-usb) для
большинства устройств, для Lenovo и Xiaomi — фирменный драйвер с сайта
производителя.

Проверка:

```powershell
& $env:ADB devices
```

Должна быть строка `SERIAL123456   device`. Если написано `unauthorized` —
не нажали «Разрешить» на планшете. Если `offline` — переподключите кабель.

## 6. Запуск

```powershell
cd C:\WunderTablet
python launcher_tui.py
```

Откроется мастер настройки. Управление:

| Клавиша | Действие |
|---|---|
| ↑ ↓ | перемещение по строкам |
| Пробел, ← → | изменить значение |
| Enter | запустить прогон |
| q | выход |

**Рекомендуемые настройки для потока планшетов:**

```
Сколько планшетов обработать     конвейер (бесконечно)
Автомод (без подтверждений)      да
Ставить MDM, если его нет        да
Вести таблицу учёта              да
Спрашивать ФИО и класс ученика   нет      ← если ФИО не нужны
```

Первый раз стоит поставить **«Сухой прогон — да»**: скрипт покажет все команды,
но ничего не изменит.

Дальше цикл: подключили планшет → скрипт всё сделал сам → строка `ИТОГ` →
надпись «отключите планшет» → отключили, воткнули следующий. Выход — `q`.

## 7. Что скрипт сделает с планшетом

1. Поставит `hmdm.apk`, если MDM-агента нет, и выдаст ему разрешения.
2. Назначит MDM владельцем устройства (device owner), если владельца нет.
3. Закрепит MDM домашним экраном.
4. Снесёт заводские лаунчеры, лишние браузеры, голосовые ассистенты,
   режим ПК и Google Meet.
5. Запишет планшет в `inventory.csv`: серийник, модель, характеристики,
   Google-аккаунт, что именно было снято.

## Если что-то пошло не так

**`python : The term 'python' is not recognized`**
Python не в PATH. Переустановите его с галочкой «Add python.exe to PATH» либо
запускайте полным путём: `C:\Users\<вы>\AppData\Local\Programs\Python\Python31x\python.exe`.

**`На Windows нужен модуль curses: pip install windows-curses`**
Ровно то, что написано. Если `pip` не найден — `python -m pip install windows-curses`.

**`adb не найден` / TUI бесконечно пишет «ожидание планшета»**
Скрипт не нашёл `adb.exe`. Положите папку `platform-tools` прямо в
`C:\WunderTablet\` — этого достаточно, поиск её подхватит. В мастере TUI
строка `adb:` вверху показывает, какой файл взят; если там красное
`НЕ НАЙДЕН` — скрипт до планшета даже не дошёл.

Важно: «adb видит планшет, когда пишу напрямую» и «скрипт не видит» — это
почти всегда **разные adb**. В командной строке у вас может работать
`.\platform-tools\adb.exe` из текущей папки, а скрипт до версии 2.2 искал
только в `PATH`. Теперь ищет и рядом с собой.

**Планшет в списке, но со статусом `unauthorized`**
На экране планшета не нажали «Разрешить отладку по USB». TUI пишет об этом
отдельной строкой и продолжает ждать.

**Вместо рамок и галочек — квадраты и знаки вопроса**
Старый `cmd.exe` с растровым шрифтом. Запускайте из **Windows Terminal** или
PowerShell 7, а в свойствах окна выберите шрифт **Consolas** или
**Cascadia Mono**. Помогает также `chcp 65001`.

**Не вводится кириллица в поле ФИО**
Особенность сборки `windows-curses`. Выключите в мастере строку
«Спрашивать ФИО и класс ученика», а имена проставьте потом прямо в
`inventory.csv` — колонки «ФИО ученика» и «класс» в конце, планшет ищется по
колонке «серийный».

**`INSTALL_FAILED_USER_RESTRICTED` при установке MDM**
На планшете запрещена установка по USB. В «Для разработчиков» включите
**Установка через USB** (на Xiaomi она отключена по умолчанию и требует
входа в Mi-аккаунт).

**`DELETE_FAILED_USER_RESTRICTED` при сносе приложений**
Это не ошибка скрипта: ваш MDM как владелец устройства выставил запрет
`no_uninstall_apps`. Скрипт распознаёт это и сам переходит в режим отключения
приложений. Чтобы именно удалять — снимите запрет в консоли Headwind MDM,
примените конфигурацию на планшет и повторите прогон.

**Таблица `inventory.csv` открывается в Excel одной кашей**
Файл в UTF-8 с BOM и разделителем `;` — Excel открывает его корректно по
двойному клику. Если вы открываете через «Данные → Из текста», укажите
разделитель «точка с запятой» и кодировку UTF-8.
